# 项目经历

## GPUNexus - 跨平台AI助手应用
**职位**: 前端负责人 | **时间**: 2025.11 - 至今

### 项目概述
主导开发基于React Native的跨平台AI助手应用，集成本地推理、远程推理与GPU算力分享功能，构建完整的移动端AI服务生态。

### 核心功能模块

#### 1. 混合推理引擎前端实现
- **双引擎架构**: 负责前端智能调度逻辑，根据设备性能、网络状况动态选择本地GPUF SDK或远程OpenAI API
- **性能优化**: 实现流式渲染、数据预加载策略，本地推理延迟<500ms，用户感知性能提升300%
- **多模态交互**: 设计文本+图像复合输入界面，支持视觉理解、文档分析等复杂场景
- **资源调度**: 参与前端资源调度算法设计，优化模型加载和卸载策略

#### 2. GPU算力分享经济系统
- **P2P网络交互**: 实现去中心化模型服务网络的P2P连接状态展示与交互界面
- **实时计量系统**: 开发Token级精确计量前端展示模块，支持毫秒级用量统计和实时结算
- **原生SDK集成**: 深度参与GPUF C++ SDK的React Native桥接模块开发
- **智能合约**: 实现基于区块链的收益分配机制前端展示和操作界面

#### 3. 企业级用户生态
- **分布式认证**: 实现JWT + Session双重认证机制前端逻辑，支持单点登录和跨设备同步
- **高并发处理**: 优化前端渲染性能和网络请求策略，支持万级并发用户，P99响应时间<200ms
- **数据安全**: 实现前端端到端加密存储和传输的UI/UX设计，符合GDPR数据保护标准
- **智能运维**: 构建前端监控告警体系，实现故障自愈和弹性扩容的可视化界面

### 前端技术突破

#### 1. 原生性能优化
- **内存管理**: 优化React Native侧大模型加载策略，通过JS/Native内存桥接优化，内存占用降低40%
- **并发处理**: 实现前端多任务并发推理的UI/UX设计，支持同时处理3+推理任务的流畅切换
- **热更新**: 设计并实现模型热更新的前端提示与加载机制，无需重启即可切换模型
- **功耗控制**: 优化前端动画和渲染逻辑，设备功耗降低25%，延长续航时间

#### 2. 跨平台兼容性
- **统一架构**: 主导设计iOS/Android统一React Native代码架构，代码复用率达95%
- **平台适配**: 针对不同平台特性进行前端UI/UX优化，iOS性能提升15%，Android稳定性提升30%
- **原生集成**: 开发原生桥接模块，实现React Native与底层功能无缝对接
- **测试覆盖**: 建立完整的自动化测试体系，测试覆盖率达90%

### 技术栈
- **核心框架**: React Native 0.70+, TypeScript, MobX
- **UI组件**: React Native Paper, React Native Elements, Lottie
- **导航路由**: React Navigation 6+, Deep Linking
- **状态管理**: MobX State Tree, AsyncStorage, WatermelonDB
- **网络通信**: Fetch API, WebSocket, SSE, Axios
- **原生集成**: Native Modules, NDK, JNI, CocoaPods
- **开发工具**: Flipper, Reactotron, CodePush, Sentry
- **测试框架**: Jest, Detox, React Native Testing Library
